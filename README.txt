Daily Expenses app - how to put it on your phone

1. Upload this whole folder to any free web host that gives an https link:
   - Netlify Drop (app.netlify.com/drop): drag the unzipped folder onto the page.
   - or GitHub Pages / Cloudflare Pages.
2. Open the https link in Chrome on your phone.
3. Menu (three dots) > Install app. It now opens full screen with its own icon and works offline.

Your entries are saved on the phone. Use the CSV download buttons for backups.
